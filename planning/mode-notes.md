# Mode Notes

## Current Mode: Solvable Practice

- Each round is dealt as an independently generated solvable 4-card hand for
  the selected target.
- This preserves the 13-round structure without requiring a single shuffled deck
  to partition into 13 solvable hands.
- The no-solution judgment action is intentionally out of the active play flow
  while every dealt hand is guaranteed solvable.

## Future Mode: No-Solution Challenge

- Use a fully random shuffled deck and play all 13 four-card deals from that
  deck.
- Reintroduce no-solution judgment, scoring, and feedback only for that mode.
- Keep this separate from solvable practice so players understand whether every
  hand is supposed to have an answer.
