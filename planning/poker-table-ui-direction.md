# Poker Table UI Direction

## Chosen Visual System

The active game should feel like a compact poker table for phone play: green
felt, ivory cards, warm brass accents, chip-like status counters, and clear
action zones. The table is the main surface, not a generic app page.

## Reference Borrowing

- From poker/casino tables: green felt surface, card hand area, chip counters,
  strong contrast between cards and table, and a clear action rail.
- From playful poker deckbuilders: energetic score feedback, chunky badges,
  saturated accent colors, and a slightly theatrical game-table mood.
- Not borrowed: specific layouts, characters, jokers, art assets, typography,
  scoring systems, or copyrighted visual compositions.

## Interaction Priorities

- Keep the four fixed operation rows visible and readable on narrow screens.
- Keep cards large enough to drag comfortably on a phone.
- Make result cards feel like newly dealt table objects returning to the pool.
- Treat undo as the only active command in solvable practice mode.

## Palette

- Felt green: `#063B2B`, `#0A5C3B`, `#0F7A4D`
- Rail/wood dark: `#21150D`, `#3A2415`
- Brass/gold: `#F4C95D`, `#C89432`
- Card ivory: `#FFF8E7`
- Chip accents: red `#C2413A`, blue `#2563EB`, cream `#F8E7B1`
